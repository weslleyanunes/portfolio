Project Management System (Sistema de Gestão de Projetos) is a secure, self-contained desktop application for managing users, projects, and tasks. Built with Java Swing, it offers a modern and consistent user experience with features like secure password authentication, a password recovery system, and a light/dark theme toggle—all functioning with local file-based persistence, requiring no database server.

Built using Java with key libraries including FlatLaf for the modern UI and jBCrypt for secure password hashing.
